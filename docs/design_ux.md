## The logging experience

### Speed

*How fast should starting a workout feel? What's the max acceptable tap count to get to a first set?*
3

### Defaults and memory

*What should the app remember? Previous weights? Last session type? Recent exercises? Where should it surface these?*
I don't want to pre-fill to much. Start blank for most stuf. But as soon as a user starts typing a previously used exersize or training type should be available as dropdown option. 

### Inline vs modal

*When is it OK to open a modal or new screen? What must always stay inline?*
Maybe compliated tweak analysis views of some specific stats over a specific time. 


### Finishing a workout

*What happens when the user taps "Finish"? What do they see? What's optional vs required?*
They should have some overview where they see it logged. Maybe a calender type of view. Or just a small table on there home screen of the app. Or something even more subtle, 
like a stat of 'training session this week' that increased by 1.
